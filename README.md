## Google Sheet 세대 인증

루트 위저드와 `map + variant` 딥링크는 Google Apps Script 인증을 통과해야 쇼케이스로 진입합니다. 사용자가 선택한 세대의 층·호수는 전송하지 않고, 카탈로그에서 계산한 동·타입과 입력한 닉네임만 대조합니다. `인증됨`은 쇼케이스를, `운영자`는 검수맵 관리·건축물 관리·인테리어 관리·전체 동호 현황까지 허용합니다. 일반 가이드는 공개되지만 인증 설치 가이드는 운영자 세션에만 목록으로 표시됩니다.

GitHub Pages의 정적 파일 자체는 계속 공개되므로 이 절차는 비공개 자산 접근통제가 아닌 사이트 UI 인증입니다. 시트 상태를 바꾼 뒤에는 사용자가 **인증 확인**을 다시 눌러야 현재 탭의 역할이 갱신됩니다.

Sheet의 `가입요청 → 승인 → 인증명단` 운영 절차, 운영자 코드 설정, 기존 요청 백업·이동과 재배포 방법은 [`backend/apps-script/README.md`](backend/apps-script/README.md)에 정리되어 있습니다. **Google 웹앱 개정 2를 먼저 배포한 뒤 Pages를 갱신하세요.** Spreadsheet ID·명단·운영자 코드는 저장소 및 배포 산출물에 넣지 않습니다.

- 원본 Three.js 소품 레시피 83종과 Blender GLB 중간 LOD 5종
- 캐릭터 에셋 키 100·200
- 기본 공격, 쇼크스턴, 더블애로우, 텔레포트와 원본 스킬 아이콘·효과
- 5칸 핫바(텔레포트·성별 전환·거실 방향 전환·변신·자녀 인형), 옵션 팔레트와 견적·소품 갱신

- 선택 옵션이 하나 이상이면 사전청약·본청약 납부 일정, 마이너스 옵션 감액, 선택형 취득 관련 세금·전용 모기지를 계산하고 A4 인쇄·PDF 저장 가능
- 시스템에어컨 일반형·고급형 카드별 설치 대수 증감과 인게임형 좌하단 선택 옵션·합계 바
- 우측 상단 선택 평면의 실시간 미니맵과 조작 캐릭터 위치·방향 표시
- 맵별 로컬 검수 상태, 메모, 옵션 조합, JSON 백업·복원
- 원본 인테리어 미리보기 83개를 쓰는 메인 PBR 가구 배치와 검수 관리자 2D·3D 배치·이동·회전·반전·복제·크기 조절·JSON 백업
- 건축 구성 트리·2D 평면·Three.js PBR·원본 속성·로컬 검수 JSON을 묶은 독립 건축물 관리자
- 같은 가구 이미지와 배치 좌표를 사용하는 독립 인테리어 관리자

단지 전체맵, 구조·벽 자체 편집, 서버 publish와 revision 복구는 공개본에서 제외합니다. 관리자의 가구 배치는 브라우저 로컬 초안일 뿐 원본 PVP에 반영되지 않습니다.

## 조작법

- `WASD` 또는 방향키: 인게임과 동일한 32×24px 투영에서 420ms마다 정수 셀 한 칸 이동. 이동 중에는 출발 방향을 유지하고 셀 도착 뒤 다음 입력 방향을 적용
- 상단 평면 타입(운영자) 또는 핫바 3번: 평형별 2~4개 방향을 순환하며 구조물·가구·충돌 셀이 함께 변환
- 캐릭터 클릭 또는 상단 선택기: 돌범(100)·피치(200) 조작 대상 전환
- 캐릭터 몸통에 커서를 올리면 이름 표시, HP 표시는 없음
- 숫자키 `1`–`5` 또는 핫바 클릭: 텔레포트·성별 전환·거실 방향 전환·변신·자녀 인형
- Space: 기본 공격. 팝업과 입력·버튼 조작 중에는 게임 단축키를 실행하지 않음
- `1` 또는 마우스 휠 클릭: 아파트 내부 텔레포트, 재사용 간격 2초
- 빈 맵 좌클릭 드래그: 손바닥 커서로 카메라 이동(캐릭터 선택 또는 위치 초기화로 추적 복귀)
- `Ctrl+마우스 휠`: RPG 기준 100%에서 커서 위치 중심으로 건물·배경·캐릭터를 함께 확대·축소 (`Shift+휠`은 선택 가구 회전)
- 메인 `가구 배치`: 원본 이미지 카드 선택 후 PBR 바닥 클릭, 배치 후 화면이나 `적용만 보기` 목록에서 다시 선택, 드래그 이동·미니 도구 재배치·`Shift+휠` 회전·`Del` 삭제
- 옵션 화면 가구: 좌클릭하면 RPG식 금색 선택 마스크와 이름표 표시, 우클릭하면 조작 메뉴 표시, `L`은 현재 회전을 유지한 채 1.15m 안의 가장 가까운 벽면으로 자석 스냅
- 옵션·가구 팔레트: 탭 본문 전체를 세로 스크롤하며 `적용만 보기`로 현재 적용 옵션 또는 실제 배치 가구만 필터링
- 레이저 실측: 첫 `J`는 자동 실측을 시작하고 이후 `J`마다 자동 ↔ 2점 실측을 전환하며, `Esc`로 종료. 2점 실측은 벽·설비·가구 면에 첫 점을 자석 고정하고, `L OFF`에서는 마우스로 원하는 자유 종점을 찍음
- 2점 실측 방향 제한: `L OFF`에서 `Shift`를 누르는 동안 세대 로컬 X/Y 네 방향 중 마우스에 가까운 직선으로 제한하되 반대 면까지 연장하지 않고 마우스 투영점에서 끝남. `L ON`은 기존처럼 반대쪽 벽·가구 면까지 직선 자석으로 측정하고 `Shift+휠`로 축을 수동 전환
- 캐릭터가 실내·북서 방향 벽 뒤로 이동하면 카메라-캐릭터 시선을 가리는 벽만 부드럽게 반투명 처리
- 관리 페이지 2D·3D: 양쪽 화면에서 드래그 이동, 0.05m 스냅, ±90° 회전·반전·복제·크기 조절·삭제
- 직접 링크: `/?map=<mapId>&variant=A|B|C|D` (평형별 지원 타입만 적용)

이 사이트의 스킬 쿨다운과 효과는 프론트엔드 시연용입니다. 실제 피해, 명중, MP, 서버 판정을 표현하지 않습니다.

## 분양가·납부 계산기

쇼케이스 좌하단에서 옵션을 하나 이상 선택하면 `분양가 계산기`가 활성화됩니다. 계산기는 인증 과정에서 산출한 **타입과 층 가격구간만** 현재 탭의 `sessionStorage`에 보관하며 동·호·실제 층·닉네임은 URL, 계산 컨텍스트 또는 인쇄물에 남기지 않습니다. 공급대금·발코니 확장비·마이너스 옵션 감액과 납부 일정은 분당퍼스트빌리지 공고문을 기준으로 하고, 세금과 대출은 사용자가 펼쳐서 입력하는 참고 추정치입니다.

대출 안내는 LH 신혼희망타운 전용 모기지의 현재 공개 조건을, 취득 관련 세율은 지방세법과 지방세특례제한법의 현재 기준을 따릅니다. 실제 입주·대출 실행 시점의 법령, 기금운용계획, 금융기관 심사와 각종 부대비용에 따라 달라질 수 있으므로 계약·세무·대출 의사결정의 확정 금액으로 사용하지 않습니다.

2026-10-22 자금 정보 보완에서는 기존 계약총액·납부표를 유지하면서 중도금 대출 상환원금까지 포함하는 입주 정산, 미납 부대비용, 세전 매각 회수액을 구분합니다. 모기지 기준은 공식 상품의 공급가+발코니(기타 옵션 제외)이며 4억원 상한의 실효 LTV·전체 연도별 정산표를 반영합니다. 소득·동호·닉네임·자산 입력은 추가하지 않으며 계산 가정은 현재 탭의 `sessionStorage`에만 유지합니다. [입주·자금 계산 가이드](src/guides/content/sale-finance.md)에 출처·확정/미정/가정 구분과 감면 기한을 정리했습니다.

## 로컬 개발

Node.js 22 이상이 필요합니다.

```bash
npm ci
npm run dev
```

포털은 `http://127.0.0.1:5174/naksaeng/`, A1 앱은 `http://127.0.0.1:5174/naksaeng/bunfirvil/`에서 확인합니다. 개발 서버는 다음 포트도 A1 내부 서버용으로 사용하므로 5174·5175를 함께 비워 두세요. `--port 5180`이면 5180·5181을 사용합니다. `npm run preview`는 빌드된 두 화면을 4173 포트에서 제공합니다.

주요 검증 명령:

```bash
npm run test:unit
npm run build
npm run verify:dist
npx playwright install chromium
npm run test:smoke
```

PVP 원본의 선별 자산 snapshot을 갱신할 때만 다음 명령을 사용합니다. 원본 저장소에는 쓰지 않습니다.

```bash
npm run sync:assets -- --source ../pvp
```

추출 결과는 `public/generated/exports/<exportId>/`에 버전 고정되며 `source-export.json`에 원본 HEAD, dirty 여부, 파일별 SHA-256이 기록됩니다. 맵 구조물 JSON, 공개 승인된 GLB, Three.js 소품 레시피, 옵션 미리보기 41개와 가구·가전 팔레트 미리보기 83개도 같은 snapshot에 고정됩니다.

## 공개 자산 정책

추출기는 명시적 화이트리스트만 허용합니다. runtime에 필요한 맵 JSON, minimap, 정제된 캐릭터 manifest와 sheet, 선택된 스킬 아이콘·효과, 공개 승인된 Blender GLB·Three.js 레시피·옵션 데이터만 포함합니다. 하드코딩된 추출 경로는 [`config/public-assets.allowlist.json`](config/public-assets.allowlist.json)의 유지관리자 검토 공개 승인 목록과 정확히 일치해야 하며, 외부·미확인·권리 불명 자산은 기본 거부됩니다.

이 승인 목록은 프로젝트 운영을 위한 maintainer-reviewed publication approval이며, 소유권이나 재배포 권리에 대한 법적 증명이 아닙니다. 공개 전 최종 권리 확인 책임을 대체하지 않습니다.

다음 항목은 공개하지 않습니다.

- 원본 sprite frame과 작업용 source 폴더
- 참조 사진, 감사 로그, draft, DB와 환경 파일
- 사용자·작업자 식별자와 절대 로컬 경로
- 재배포 권리를 확인하지 못한 외부 자산

원본 런타임의 raster `hud_bottom.png`는 출처가 프로젝트 밖으로 연결되어 공개본에서 제외했습니다. 대신 같은 런타임의 슬롯 크기, 간격, 키 표기와 쿨다운 형태를 CSS로 옮기고 서버리스 데모 액션 4개만 남겼습니다.

캐릭터 이름과 인게임 HUD에는 PVP 런타임이 사용하던 [Swei Spring](https://github.com/max32002/swei-spring) 계열 폰트를 현재 화면 글자만 포함한 WOFF2 서브셋으로 사용합니다. 배포본에는 원 저작자가 제공한 [`SIL Open Font License 1.1`](public/licenses/SweiSpring-SIL-OFL-1.1.txt)을 함께 포함합니다.

GitHub Pages에 포함된 파일은 누구나 내려받을 수 있습니다. `operatorOnly`나 `privateMap` 같은 원본 서버 플래그를 보안 경계로 사용하지 않습니다.

## 배포

정본 저장소는 [`is2js/naksaeng`](https://github.com/is2js/naksaeng)입니다. `main`에 push하면 GitHub Actions가 단위 테스트, 정적 빌드, 누출 검사와 Chromium 스모크를 한 번 수행한 뒤 Pages artifact를 배포합니다. 포털은 `/naksaeng/`, A1 앱은 `/naksaeng/bunfirvil/`을 각각 독립 base로 빌드하고 하나의 `dist`로 묶습니다. 생성 snapshot·이미지·폰트는 A1 아래에 한 번만 포함하며 전체 50MiB 예산을 검사합니다.

기존 `is2js/bunfirvil` 저장소는 주소 호환용으로 보존합니다. 새 Pages가 정상 배포된 뒤에만 기존 진입 HTML을 전환하며 기존 정적 자산은 유지합니다. 기존 루트·관리·가이드·계산기 경로의 query와 공유 fragment를 새 A1 주소로 그대로 전달합니다. 두 주소는 같은 `is2js.github.io` origin이므로 기존 브라우저 저장 키를 복사하거나 바꾸지 않습니다. 이전 계산기 복귀 경로는 승인된 map·actor·variant만 새 경로로 정규화합니다. 문제 발생 시 이전 커밋을 revert하여 복구하며 저장 데이터나 Git 이력을 초기화하지 않습니다.

Pages 검증·배포 runner는 Playwright 시스템 의존성 설치를 위해 `ubuntu-24.04`로 고정합니다. `ubuntu-latest`의 26.04 전환 중 패키지 저장소 403이 발생한 이력이 있으며, 브라우저 검사를 건너뛰는 대신 검증된 배포 환경을 유지합니다.
