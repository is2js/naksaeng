# A1 동 선택 3D 교체와 복구

기존 위저드의 첫 동 선택 영역에서 3D 모형을 바로 불러온다. 준비되는 동안에도 기존 카드는 렌더링하지 않는다. 지도나 데스크톱 오른쪽의 작은 동 목록에서 선택하면 건물 외곽에만 민트색 윤곽선이 나타나고, `NNN동 세대 선택`을 눌러 기존 세대 화면으로 간다. 공유 열람 인증의 동 선택과 세대·닉네임 단계는 기존과 같다.

- 즉시 카드로 들어가는 주소: [기존 카드로 동 선택](https://is2js.github.io/naksaeng/bunfirvil/?buildingPicker=cards). 쿼리가 있는 동안 3D 모듈을 요청하지 않으며 저장·인증 규칙은 그대로다. WebGL/WASM 또는 모델 로드에 실패해도 자동 전환하지 않는다. 오류 화면에서 `다시 불러오기` 또는 `기존 카드로 선택`을 직접 고를 수 있다.
- 서버/저장 키, 세대 카탈로그, 정적 경로는 변경하지 않는다. `#building=105`처럼 유효한 세대 단계 딥링크는 3D를 로드하지 않는다.
- 교체 전 운영 소스: [GitHub 백업 태그](https://github.com/is2js/naksaeng/tree/bunfirvil-before-3d-picker-2026-11-23), 커밋 `178946d73c6850f45f2fc77c3960ab6618b24941`. 이 버전을 올린 [Pages 실행 기록](https://github.com/is2js/naksaeng/actions/runs/44443101467)도 보존되어 있다.
- 제품 기본값 전체를 복구하려면 `git revert`로 3D 선택 화면의 후속 변경을 최신순으로 되돌린 뒤 도입 커밋 `d3c714e`를 되돌리고 `main`을 푸시한다. 이후 커밋을 삭제하는 reset/강제 푸시는 필요 없다. Pages 성공 후 일반 루트의 카드, 직접 링크, 모바일 세대 선택을 확인한다.

## 단지 시설 범례

단지배치도 PDF 4쪽 왼쪽 상단의 실제 표기를 기존 북향 좌표계에 옮겼다. `시설 범례`에서 종류별로 볼 수 있으며, `전체 보기`로 되돌릴 수 있다. 모든 시설이 선택 가능한 아파트 동을 뜻하는 것은 아니다. 도면과 다른 모델 표고가 있으면 해당 모델의 지면·테라스·지붕을 따라 표시하고, B1 시설은 타워 지붕이 아닌 도면의 지상 위치를 가리킨다. 빨간 오각형은 주거용 쓰레기 분리수거장만 의미한다(청록색 오각형의 근린생활시설 분리수거장은 제외).

`시설 범례`는 우상단 `다시 한눈에` 아래에 둔다. 전체 보기에는 주·부출입구와 커뮤니티센터 이름만 표시하고, 나머지 시설 기호는 그대로 두며 145%부터 이름을 표시한다. 시설 이름은 동 번호와 달리 배경 없는 작은 글씨다. PC에서 왼쪽 드래그는 회전, 오른쪽 드래그는 화면 이동이며, 오른쪽 클릭으로는 초기화되지 않는다. 초기화는 `다시 한눈에` 버튼으로 한다.

어린이집 지붕은 노란색 반투명 면, 커뮤니티센터 1·2는 PDF에 그려진 B1 구역의 지상 범위를 따라 빨간색 반투명 면으로 표시한다. 커뮤니티센터 외형은 도면 4쪽의 경계와 투시도, 6쪽 조감도를 사용해 유리·석재 입면과 연속 옥상을 모델에 덧붙여 보정한다. 상단지 가운데 부출입구와 어린이집 현관은 6쪽을 근거로 재구성하며, 105동 옆 지하차도는 유지한다.

커뮤니티센터 Ⅱ와 어린이집 이름만 작은 배경 버튼으로 표시한다. 누르면 5쪽 컷어웨이와 배치도 방위를 맞춘 3D 단면을 열며, 커뮤니티센터 B1과 어린이집 1·2층을 층별로 둘러볼 수 있다. 모형의 방이나 공간 목록을 눌러 이름과 용도를 확인한다. 캐릭터 조작은 없으며, 축척·세부 치수와 단면의 추정 부분은 시공용이 아니다. 최초 단지 화면에서는 상세 뷰어를 불러오지 않고, 원본 PDF·사진·GLB는 교체하지 않는다.

## 공개 자산

공개 파일은 로컬에서 자체 제작한 `src/site-preview/assets/bunfirvil-site-v9.glb` 한 벌(731,620바이트, 49,227 삼각형)과 Three.js의 로컬 WASM 디코더다. 첨부 단지배치도와 모형 사진은 배치의 참고이며 PDF·사진 원본·Blender 편집 원본·로컬 시안 페이지는 배포하지 않는다. 장면은 시공 치수나 정확한 고도를 보장하지 않는다. `scripts/verify-dist.mjs`가 승인된 GLB 해시, 단지 모형/디코더 1.2 MiB, 나머지 앱 50 MiB, 전체 100 MiB 한도를 확인한다.
