# 55B 정본·벽 마감·참고 평면도 개선

## 승인 범위와 원인

- 55B 원본은 현관 벽 안쪽 간격 2.58m와 별도 1.55m 중문 제한, 현관문과 독립된 신발장 앵커가 결합되어 큰 틈을 만들었다. 알파룸·침실2의 깊이 초과도 수동 공간 좌표와 치수 annotation이 분리된 데서 발생했다.
- 외곽을 고정한 채 현관만 줄이면 욕실 또는 복도에 과도한 공간이 생겨, 사용자는 **55B만 도면 비례를 우선하고 외곽·현관문까지 함께 보정**하는 안을 선택했다.
- 방 연결과 외곽 꺾임 순서는 유지한다. PVP 원본·생성 snapshot, 다른 세 평형의 기하, 옵션 ID·가격·인증·계산기·저장 키는 변경하지 않는다.
- 기존 저장·공유 가구의 좌표는 자동 이동하거나 삭제하지 않는다.

## 55B geometry v2

- 원본 로드 직후 알려진 55B 원본에만 로컬 정본을 한 번 적용하고, 그 뒤 기존 A–D 변환을 수행한다. 55B에는 기존 50mm 보정표를 중복 적용하지 않는다.
- 외벽 200mm, 일반 내벽 120mm, 욕실 공유벽 200mm는 가상 모델의 작성값이지 실제 시공 확정값이 아니다.
- 명시된 파란 치수 12개는 실제 벽면 또는 열린 구획의 기준선으로 대조한다. 참조선 위치에 가짜 벽을 넣거나 레이저 숫자를 치환하지 않는다.
- 현관 폭 1.50m와 팬트리 폭 약 1.00m는 첨부 도면 비례에서 추론한 값이다. 알파룸의 `18` 표기는 기존처럼 1.8m로 잠정 판독한다.
- 중문은 실제 recipe의 프레임 외곽을 기준으로 양쪽 약 10mm 여유를 둔다. 반개방 패널 사이의 의도된 통로와 프레임 바깥의 잘못된 빈틈을 구분한다.
- 신발장·팬트리·욕실·주방·수납 옵션의 앵커를 같은 정본의 벽면에 연결한다. 제품 가구를 일괄 축소하지 않는다.
- 새 기하에 따라 통행·충돌·텔레포트 착지와 미니맵이 갱신되어야 한다. 기존 raster mask가 새 벽이나 설비 안 착지를 허용해서는 안 된다.
- 새 공유에는 선택적인 `geometryRevision`을 기록한다. 예전 v1 공유는 계속 열고 구조 변경 안내를 표시한다. 충돌·바닥 밖 가구는 원래 좌표를 보존한 채 재배치 필요 여부만 안내한다.

## 기본 벽과 A042 재질

공식 마감재리스트의 공용부 서울 실크형벽지 4092-2, 침실·드레스룸 4252-5, 디자인월 및 인피니티 도어 복도면 동화 A042 LILT GRAY를 참고했다.

- 기본 벽은 갈색 tint와 따뜻한 원본 texture가 중복 곱해지던 구성을 제거하고 회백·중성 아이보리의 실크 벽지 결을 사용한다. 기본 마감을 시멘트라고 안내하지 않는다.
- A042는 색상·미세 석질 입자·bump·roughness를 함께 표현하며 도어 복도면도 같은 texture 세트와 미터 UV를 사용한다. 색은 견본 기반 근사이며 색 보정된 제조사 RGB가 아니다.
- 구조벽과 도어의 기존 면을 교체한다. 이중 덧판·겹친 줄눈·공면 outline을 피하고 물리 실측에는 마감 두께를 추가하지 않는다.
- 55B 새 침실1 도어 위 상인방도 기본 TV벽의 A042 면에 포함한다. 도어 위에 옛 기본 벽지 띠가 남지 않으며, 마감 대상 면만 추가하므로 구조·실측은 바뀌지 않는다.
- texture만 공유하고 벽별 material의 투명도는 독립시킨다. 구조 단면은 중성 회색이며 실내 제공 마감과 구분한다.

## 참고도·가이드·실측 안내

- 미니맵은 현재 평형의 사용자 제공 치수도 한 장을 여는 접근 가능한 버튼이다. 모달은 1–4배 휠·pinch 확대, 확대 후 이동, 맞춤, 다운로드, 배경 탭·Esc 닫기와 포커스 복원을 제공한다.
- 글자가 뒤집히지 않도록 원본 이미지를 회전·반전하지 않는다. 현재 놀이터 방향 및 실제 시공과 다를 수 있음을 표시한다.
- 사용자가 공개 열람·다운로드를 승인한 PNG 4장은 원본 해시 그대로 `public/assets/floorplans/`에 보관한다. manifest에 출처 종류와 승인 범위를 기록하고 기기 로컬 경로·개인정보는 넣지 않는다.
- 모달에서는 이동·실측 입력을 격리하며 확정한 실측점은 유지한다. 공유 열람에서도 제공한다.
- 상세 실측 비교 가이드는 운영자 전용 목록과 본문에서만 제공한다. 정적 자산 자체가 비공개 보안 경계인 것은 아니다.
- 실측 최초 경고는 상단에서 3초 후 즉시 숨긴다. hover·focus·BFCache 복귀로 시간을 연장하거나 다시 표시하지 않는다. 경고가 있는 동안 상단 HUD와 미니맵은 안내줄 아래로 잠시 이동한다.

## 배포 자산 보존

새 도면 자산을 기존 50MiB 앱 한도 안에 포함하기 위해 사용하지 않는 옛 대표 이미지 `public/og.png`를 `docs/assets/reference/og-original.png`로 이동했다. 원본 SHA-256은 `4c8c0433d08adda58600d164bdbe69653c7b0093f16f00eba75a1c9f47d1d02c`로 동일하며 재생성 provenance의 참조 경로를 갱신했다. 현재 배포 대표 이미지 `og-playground-v3.jpg`는 변경하지 않았다.

## 검증 결과

- 관련 10개 파일의 단위 검사 308개가 통과했다. 46개 치수×A–D 184개 대응과 55B 새 물리 면/기준선 12개, 통행·텔레포트·실제 recipe 외곽·공유 호환·가이드 권한·3초 경고·이미지 제스처를 포함한다.
- 55B 12개 치수의 모델 오차는 0mm, 현관 1,500mm·팬트리 1,000mm, 중문 양끝 10mm·현관문 인접 신발장 끝 20mm다. 참조선/추론값과 실제 시공 확정값을 구분한다.
- production build와 정적 출력 검사가 통과했다. 앱 49.65MiB / 공개 문서 42.67MiB로 기존 각각 50MiB 한도를 유지했다.
- PC 1440px·모바일 390px를 묶은 Chromium 한 흐름이 통과했다(3.2분, JS 오류 0건). 실제 화면에서 기본 벽/디자인월/인피니티 도어와 중문·신발장·팬트리, 도면 휠·pinch·드래그·배경 닫기·다운로드, 모달 중 이동 차단과 확정 실측 보존, 운영자/회원 가이드 구분 및 가로 넘침 없음을 확인했다.
- 화면은 로컬 `test-results/laser-interaction-laser-re-7fcff-ce-notice-work-on-PC-mobile/`에 보관한다. 공개 자산에 검수 화면이나 사용자 테스트 상태를 복사하지 않는다.
- 스모크의 카메라 확대 보간 중 0.1mm 미만 프리뷰 변화는 표시 정밀도 1mm로 비교하며, 확정 후 선 양끝·표시 mm 일치 및 모달 왕복 좌표 보존은 별도로 검사한다. 옵션 클릭 후 카테고리가 이동하는 정상 UX도 검사 순서에 반영했다.
- 전체 로컬 테스트와 별도 성능 감사는 수행하지 않았다. Pages의 기존 필수 workflow는 유지한다.
- Pages 소프트웨어 WebGL 실행에서 동일한 실측 흐름은 한 번 6.2분에 통과했으나 다른 실행에서 8분 전체 제한을 초과했다. 기능 검증을 유지하며 CI의 PC·모바일 합산 예산만 12분으로 설정하고 단계별 경과를 남긴다(로컬 5분 유지). 변신 해제의 상태·인라인 위치 복원도 같은 DOM 스냅샷에서 검사하며 CI 응답 대기는 30초로 제한한다. 제품 동작이나 다른 배포 검사는 변경하지 않는다.
