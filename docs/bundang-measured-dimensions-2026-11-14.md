# 분당퍼스트빌리지 도면 치수·모델 보정 감사

기준일: 2026-11-14. 보정 revision: `bundang-measured-geometry-v1`.

## 근거와 보정 범위

- 사용자가 제공한 51A·55A·55B·59A 파란 치수 이미지의 46개 값을 목표로 기록했다. 공식 CAD·준공 실측값이 아니며, 이미지 원본은 공개 저장소나 배포 자산으로 복사하지 않았다.
- `bundang-measured-dimensions.ts`는 목표값과 실제 벽면/물리 요소에서 연장한 기준선을 분리한다. `targetMm`나 기존 annotation 숫자로 끝점을 덮어쓰지 않는다.
- 외곽 polygon·외벽·외부 개구부는 그대로 유지한다. 내부 벽의 중심·끝점·최종 양쪽 면 끝점 이동은 유클리드 50mm 이하이며 두께 변화도 50mm 이하로 제한한다. 공유벽 제약 안에서 각 항목의 절대오차가 나빠지지 않는 보정만 사용한다.
- 원본 source signature가 맞는 경우에만 원본을 clone해 정적 보정표를 한 번 적용한다. 생성 snapshot은 쓰지 않으며, 원본 불일치에서는 적용하지 않는다. 브라우저에서 최적화를 실행하지 않는다.
- 열린 거실 기준선이나 주방 부분 구간에 가짜 벽을 추가하지 않는다. 기존 연속된 공간을 재는 레이저는 계속 실제 벽·설비·가구 면에서 끝난다.

## 선 끝 대응과 남은 한계

- 51A 거실 깊이는 침실1 문 뒤 벽 시작점의 Y=5.8 기준선부터 남측 벽 안쪽 면까지다. 예전 annotation의 5→8 선은 사용하지 않는다.
- 55A·59A 거실 깊이 시작선도 각각 실제 벽 시작점 Y=5.85·6.05에 연결했다. 이 선은 개방 공간을 가로지르는 기준선이지 물리 벽이 아니다.
- 55A 알파룸·침실2, 59A 침실2·3의 깊이는 이미지처럼 문 오른쪽의 폐쇄된 면에서 잰다. 실제 공유벽이 겹치는 곳은 방 쪽 실제 최외측 면을 사용한다.
- 55B 거실의 두 가로 치수 오른쪽 끝은 출입구 벽 끝·주방 경계의 연장선이다. 55B 알파룸 폭의 이미지 표기는 18로 보여, 주변 화살표 비례와 기존 자료로 1.8m를 잠정 해석했다.
- 외곽과 50mm 한도, 기존 출입구의 통행 구조를 지킨 결과 큰 잔여 오차가 남는다. 특히 55B 알파룸 깊이는 약 765mm, 침실2 깊이는 약 700mm 차이가 남아 있다. 표시값을 목표 숫자에 맞춰 숨기지 않았다.

## 46개 전후 결과

단위는 mm. 표는 1mm로 반올림하며 잔여는 모델 후 − 도면 목표다. 0은 표시 정밀도에서 차이가 없다는 의미이지 실제 건축물의 시공 정밀도를 보장하지 않는다. '실제 면'은 현장 실물이 아니라 현재 모델에 존재하는 구조면이다. '기준선'은 실제 벽 끝·상판 끝 등의 좌표를 열린 공간에 연장한 참고 구간이다. 가구와 주방장 등은 이 구조 치수 표에서 제외하며, 부분 주방 기준선에 명시한 상판 경계만 참고한다.

## 검증과 재현

- 관련 단위 파일의 191개 검사 중 184개는 46개 계약 × A/B/C/D다. 변환된 양 끝점·역변환·mm 거리 일치와 개별 절대오차 비악화를 확인한다. 이 표와 공개 가이드의 46행도 실제 geometry 결과와 자동 비교한다.
- '실제 면' 계약은 130mm 높이의 실제 레이저 구조 접점과도 일치한다. 원본과 외곽 보존, 내부 중심·끝·양쪽 면 50mm 한도, idempotence, target label 변경 시 끝점 불변도 검사한다.
- 같은 선상에 가구·기본 주방장·옵션이 있으면 실제 놀이터 레이저는 그 면에서 먼저 끝나므로 이 표와 달라질 수 있다.
- 이 보고서는 가상 모델의 보정 감사다. 가구 주문·시공·계약 판단에는 공고문·전시관·현장 실측을 사용한다.

재계산은 저장소 루트에서 다음 명령으로 한다. 기본은 이 표의 Markdown, `--json`은 반올림 전 수치와 실제 끝점을 stdout으로 출력한다. 명령은 원본·문서를 자동 수정하지 않는다.

```powershell
node scripts/report-bundang-measured-dimensions.mjs
node scripts/report-bundang-measured-dimensions.mjs --json
npx vitest run src/game/bundang-measured-dimensions.test.ts
```
