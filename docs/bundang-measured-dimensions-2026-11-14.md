# 분당퍼스트빌리지 도면 치수·모델 보정 감사

개정 기준일: 2026-11-15. 51A·55A·59A 정본 revision: `bundang-measured-geometry-v2-exact`; 55B 정본: `bundang-55b-geometry-v2`.

## 근거와 보정 범위

- 사용자가 제공한 51A·55A·55B·59A 파란 치수 이미지의 46개 값을 목표로 기록했다. 공식 CAD·준공 실측값이 아니다. 사용자가 공개 열람·다운로드를 승인한 원본 4장은 별도의 참고 평면도 모달에서 제공하며 출처·해시를 기록한다.
- `bundang-measured-dimensions.ts`는 목표값과 실제 벽면/물리 요소에서 연장한 기준선을 분리한다. `targetMm`나 기존 annotation 숫자로 끝점을 덮어쓰지 않는다.
- 사용자가 **도면 치수 우선·외곽 최소 보정**을 승인했다. 51A·55A·59A는 외곽 꺾임·방 인접 관계를 유지하면서 외곽 polygon·외벽·창호·내부 벽·개구부·고정 앵커를 같은 단조 격자로 변환한다. 벽 두께는 원본의 정상 두께(내벽 120mm, 설비벽 200mm, 외벽 250mm 등)를 유지하며, 공간을 맞추려고 비현실적으로 얇은 벽을 만들지 않는다.
- 오프라인 최소변위 해의 좌표축별 최대 보정량은 51A **220mm**, 55A **375mm**, 59A **310mm**다. 이는 각 격자 좌표축의 변위이지 모든 지점의 유클리드 이동 한도나 현장 치수 허용오차가 아니다. 브라우저는 승인된 정적 표만 적용한다.
- 서로 다른 실제 면이 우연히 같은 원본 좌표를 쓰는 경우만 별도 랜드마크로 분리했다. 51A 침실1 문 끝은 10mm, 55A 알파룸 북측 벽·문·접점은 40mm, 59A 욕실2 남측 공유벽·접점은 −40mm를 먼저 분리하며 벽 두께는 바꾸지 않는다. 문 구멍은 원래 폭보다 작아지지 않도록 계산한다.
- 55B는 별도 승인에 따라 외곽·현관문까지 도면 비례로 재작성했다. 방 인접 관계와 외곽 꺾임 순서를 유지하고 현관 1.50m·팬트리 약 1.00m는 이미지 비례 추론값으로 구분한다. 기존 50mm 보정표를 중복 적용하지 않는다.
- 원본·정규화 source signature가 맞는 경우에만 원본을 clone해 정적 보정표를 한 번 적용한다. 생성 snapshot과 원본 파일 좌표는 수정하지 않으며, 원본 불일치에서는 적용하지 않는다. 기본·고정 제품은 벽에 맞춰 위치를 연결하되 제품 크기·형태를 일괄 늘이거나 줄이지 않는다.
- 사용자 저장 가구의 좌표·회전·삭제 상태와 기존 저장 키는 유지한다. 새 구조와 겹치거나 바닥 밖으로 보이는 사용자 가구는 자동 이동·삭제하지 않고 사용자가 재배치하도록 안내한다.
- 열린 거실 기준선이나 주방 부분 구간에 가짜 벽을 추가하지 않는다. 기존 연속된 공간을 재는 레이저는 계속 실제 벽·설비·가구 면에서 끝난다.

## 이전 오차와 현재 선 끝 대응

이전 v1은 외곽을 고정하고 내부 보정을 최대 50mm로 제한했다. 55A 침실1의 도면 3,300mm가 자동 실측에서 약 3,249mm였던 것은 이 제약 아래 남은 약 51mm의 실제 모델 오차이며, 레이저 표시값의 감산이나 반올림 문제가 아니었다. 현재 정본은 사용자가 승인한 외곽 최소 보정과 공유면 제약을 함께 풀어 이 잔여 오차를 제거한다.

- 51A 거실 깊이는 침실1 문 뒤 벽 시작점의 기준선부터 남측 벽 안쪽 면까지다. 원본 Y=5.8의 문 끝을 5.81로 분리한 뒤 벽·문과 함께 변환하며, 예전 annotation의 5→8 선은 사용하지 않는다.
- 55A·59A 거실 깊이 시작선도 각각 원본 Y=5.85·6.05의 실제 벽 시작점과 함께 이동한다. 이 선은 개방 공간을 가로지르는 기준선이지 물리 벽이 아니다.
- 55A 알파룸·침실2, 59A 침실2·3의 깊이는 이미지처럼 문 오른쪽의 폐쇄된 면에서 잰다. 실제 공유벽이 겹치는 곳은 방 쪽 실제 최외측 면을 사용한다.
- 55B 거실의 두 가로 치수 오른쪽 끝은 출입구 벽 끝·주방 경계의 연장선이다. 55B 알파룸 폭의 이미지 표기는 18로 보여, 주변 화살표 비례와 기존 자료로 1.8m를 잠정 해석했다.
- 51A 10개·55A 12개·55B 12개·59A 12개, 총 **46개**의 현재 모델 면/기준선 오차는 표시 정밀도에서 **0mm**다. 55B의 과거 알파룸 약 765mm·침실2 약 700mm 깊이 차이는 별도 v2 정본에서 해결한 상태를 유지한다. 실제 시공과 일치한다는 의미는 아니다.

## 46개 전후 결과

단위는 mm. 표는 1mm로 반올림하며 잔여는 모델 후 − 도면 목표다. 0은 표시 정밀도에서 차이가 없다는 의미이지 실제 건축물의 시공 정밀도를 보장하지 않는다. '실제 면'은 현장 실물이 아니라 현재 모델에 존재하는 구조면이다. '기준선'은 실제 벽 끝·상판 끝 등의 좌표를 열린 공간에 연장한 참고 구간이다. 가구와 주방장 등은 이 구조 치수 표에서 제외하며, 부분 주방 기준선에 명시한 상판 경계만 참고한다.

## 검증과 재현

- 46개 계약 × A/B/C/D에서 변환된 양 끝점·역변환·mm 거리 일치를 확인한다. 이 표와 운영자 가이드의 46행도 실제 geometry 결과와 자동 비교한다.
- '실제 면' 계약은 130mm 높이의 실제 레이저 구조 접점과도 일치한다. 정적 exact 표의 34개와 55B 정본 12개를 함께 검사하며, 원본 clone·서명 가드·원본 벽 두께·한 번만 적용·제품 크기·사용자 저장 좌표 보존을 확인한다. 목표 label을 바꾸어도 물리 끝점은 변하지 않는다.
- 같은 선상에 가구·기본 주방장·옵션이 있으면 실제 놀이터 레이저는 그 면에서 먼저 끝나므로 이 표와 달라질 수 있다.
- 이 보고서는 가상 모델의 보정 감사다. 가구 주문·시공·계약 판단에는 공고문·전시관·현장 실측을 사용한다.

재계산은 저장소 루트에서 다음 명령으로 한다. 기본은 이 표의 Markdown, `--json`은 반올림 전 수치와 실제 끝점을 stdout으로 출력한다. 명령은 원본·문서를 자동 수정하지 않는다.

```powershell
node scripts/report-bundang-measured-dimensions.mjs
node scripts/report-bundang-measured-dimensions.mjs --json
npx vitest run src/game/bundang-measured-dimensions.test.ts
npx vitest run src/game/bundang-exact-geometry.test.ts
```

정적 표 재현 검사는 numpy/scipy가 설치된 Python에서 `python scripts/generate-bundang-exact-geometry.py --check`로 실행한다. 이 검사는 런타임에서 최적화를 실행하지 않는다.
