# 기본·광폭 강마루 로컬 검토

## 근거

- 공식 55A 마감재 리스트: https://www.elife.co.kr/jsp/front/po/210114/static/pdf/210114_finishlist_55A.pdf
- 6쪽(복도/거실/주방), 20쪽(침실1/드레스룸): 기본 115×800×7.5T, 광폭 143×1200×10.5T, 단위 mm.
- 같은 공식 URL의 `51A`, `55B`, `59A` 리스트도 같은 규격을 사용한다.
- 표에는 공용부 광폭을 `DL-MISTY FLEX`, 침실 광폭을 `DL-MISTY GREY`라고 적고 일부 샘플사진도 바뀌어 있다. 따라서 제품명만으로 별도 진한 색상을 만들지 않고, 첨부 자료의 밝은 그레이지 계열을 절차형 재질로 표현한다. 화면 색상은 실제 시공 색상을 보장하지 않는다.
- 일반적인 마루 비교사진의 폭 2배가 아닌, 이 단지 규격인 폭 약 1.24배·길이 1.5배를 사용한다. 공식 샘플 사진과 원본 PDF는 공개 자산으로 복사하지 않았다.

## 구현 범위

- `bundang-floor-finish.ts`가 공통 컬러맵, 실규격 UV, 마루 선택 프록시를 관리한다.
- 기본/옵션은 같은 완성 바닥 높이에서 하나의 실제 바닥 메시 재질만 교체한다. 실제품 두께 차이 3mm를 기본 바닥 위에 덧까는 판으로 표시하지 않는다.
- UV는 회전·반전 전 원본 미터 좌표를 사용하므로 방/복도와 평면 타입이 바뀌어도 판재 크기와 방향이 일관된다.
- 기존 광폭 옵션 조각은 두께/옆면과 색상 출력이 없는 선택용 평면으로 유지한다. 전체 마루 그룹 선택·해제 복원, 옵션 가격과 저장 키는 그대로다.
- 욕실/현관 등 기존 타일 마감과 벽, 가구, 보행·레이저·가구 배치 충돌 데이터는 바꾸지 않는다.

## 로컬 확인

```powershell
npm run dev
```

터미널에 표시되는 A1 놀이터로 접속하여 같은 세대에서 광폭 강마루를 선택/해제한다. 현재 비교 캡처는 `tmp/floor-finish-review/`에 있으며 공개 빌드 자산에 포함되지 않는다. 사용자가 로컬 화면을 확인하기 전에는 커밋·푸시·Pages 배포를 하지 않는다.

최소 검사: 마루/옵션 계약 테스트 32개, TypeScript/production build, 55A 실제 Chromium에서 기본/광폭/해제와 전체 마루 그룹 선택, 1440px/390px 화면을 확인했다.
