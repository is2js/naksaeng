# 모바일 선택 옵션 이름 표시 복원

- 모바일 맵을 `clamp(600px, 80svh, 760px)`로 조금 늘린다. 기본 65% 배율과 캐릭터 추적은 유지한다.
- 데스크톱 금액 박스는 모바일에서 계속 숨기고, 기존 `#stage-option-chips` 한 개만 맵 안의 이름 전용 영역으로 이동한다. 선택 옵션이 없으면 이 영역도 숨긴다.
- 좌하단 조이스틱 위에 이름을 작은 글자로 `+` 연결하며, 가격·삭제 X·합계·계산기 버튼은 넣지 않는다. 긴 목록은 72px 안에서 내부 스크롤하여 조이스틱·핫바와 겹치지 않는다.
- 기존 클릭 핸들러·선택 마스크·팔레트 카드 연동을 재사용한다. 이름 영역은 맵 선택·패닝·실측 입력에서 제외한다.
- 계산기 버튼 한 개는 기존처럼 모바일 옵션 팔레트 하단 합계 아래에만 둔다. 데스크톱 복귀 시 칩과 버튼을 원래 부모로 되돌리며 ID·이벤트·선택 상태를 복제하지 않는다.
- 가격·인증·공유·저장 계약과 데스크톱 디자인은 변경하지 않는다.

관련 칩 동작 검사와 모바일 한 흐름에서 이름 탭, 실측 입력 제외, 조이스틱과의 간격, 팔레트 계산기 및 화면 크기 왕복을 확인한다. 광범위 로컬 검증은 추가하지 않는다.

- 칩 동작 단위 검사 2개, production build와 정적 배포 검사를 통과했다.
- 390px 터치 화면에서 이름 선택→인게임 금색 마스크·팔레트 카드 연결, 실측점 오입력 방지, 1440px 왕복 시 같은 칩/계산기 DOM 보존, 계산기 진입을 한 흐름으로 확인했다(약 1분, 페이지 오류 없음).
- 이름 목록 위의 포인터 이동도 가구 고스트나 지도 커서 좌표로 전달하지 않는다.
- 모바일 인게임의 이름 전용 표시도 160px로 제한해 긴 설명이 맵 밖으로 벗어나지 않게 한다. 옵션 전체 이름은 선택 목록에서 확인할 수 있다.
