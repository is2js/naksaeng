## 참고 사이트와 차이

- [joy-papa 옵션 계산기 예시](https://joy-papa.github.io/ebundangfirst/?type=55B&sel=6%2C42): 선택 6은 LG 프리미엄 3대 580만원, 42는 삼성 인덕션 95만원, 합계 675만원으로 카탈로그와 같다. 납부일·집단대출 계산기는 아니므로 일정 근거로 쓰지 않는다.
- [Google Sites 참고 계산기](https://sites.google.com/view/ebfb-oc?pli=1&authuser=0): 내장 계산 코드가 일반 옵션 합계를 사전 5/20/75, 신규 10/20/70으로 처리하고 중도금 날짜를 2028-02-14로 표시한다. 신규 Ⅲ의 공식 10/30/60·별도 안내와 다르므로 복사하지 않았다. 합계는 100%이며 차이는 회차 배분과 날짜다.
- 비교 링크를 사용자 계산기 UI에 새로 추가하지 않았다.

## 화면과 계산 보호

주택 중도금만 집단대출로 유입 처리하고 옵션 Ⅰ·Ⅱ·Ⅲ 중도금은 자납한다. 기존 원본 일정과 금융 계산은 이미 이 구분을 지키고 있었다.

화면상 같은 중도금 단계에 Ⅲ 준비금을 묶어 보여주되 **내 현금 · 준비 합계** 아래에 **표시 납부일 자납**과 **Ⅲ 별도 안내일 자납**을 분리한다. 총액·이자·대출·저장 계약은 바꾸지 않았다. 입주 잔금에서는 Ⅲ 잔금이 정상 포함되며, 중도금을 잔금으로 다시 합산하지 않는다.

예시 55B/580만원 에어컨/95만원 쿡탑/주택 중도금 전액 집단대출 가정:

- 신규 1차: 발코니 911,200 + 에어컨 1,740,000 = 확정일 자납 2,651,200원. Ⅲ 285,000원은 별도 고지일 자납. 신규 2차의 Ⅰ·Ⅱ 중도금은 0원.
- 사전 중도금: 발코니 911,200 + 에어컨 1,160,000 = 확정일 자납 2,071,200원. Ⅲ 190,000원은 별도 고지일 자납.

검사: 관련 금융 계약 42개(4평형·두 청약·대출/자납·Ⅲ 유무/마옵 포함), 실제 계산기 본청약/사전청약 화면의 금액 분리·모바일 표시, 모바일 팔레트 계산기 진입을 확인한다. 광범위 성능·전체 평형 브라우저 검사는 추가하지 않는다.
