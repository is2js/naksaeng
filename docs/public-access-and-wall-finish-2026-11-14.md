# 전체 공개·평면 체험·디자인월 단일 표면 개선

## 적용 정책

- `public / verified / operator`를 구분한다. 동·세대 선택 후 유효한 닉네임으로 공개 입장할 수 있고, 인증 확인은 회원 기능 승격용이다.
- 미등록·대기·반려·중지·설정/통신 오류가 회원 권한을 얻지는 않는다. 공개 입장은 가능하며 인증 재시도와 등록요청은 유지한다.
- 기존 Google 요청/응답·Sheet·Code.gs·endpoint는 바꾸지 않았다. 운영자 별도 코드와 revision 검증도 유지한다.
- 공개 기능은 옵션·계산기·이동·실측·공유와 핫바 1·2·5다. 가구 편집·평면 전환·변신은 화면 노출뿐 아니라 공통 실행 경로에서도 차단한다.
- 기존 로컬 가구는 표시하지만 편집하지 못한다. 사용자가 명시적으로 확인하는 브라우저 저장 초기화는 기존 동작이다. 공유 열람은 역할과 관계없이 기존 읽기 전용 제한이 우선한다.
- 기존 sessionStorage·localStorage 키와 schema를 유지하며 세션 role에만 `public`을 추가했다. 공개 입장을 회원 인증 성공으로 기록하지 않는다.

## 평면

모든 평형이 A–D를 제공한다. 기존 1,390세대·61개 호라인 매칭은 그대로 유지한다. 새 55B·59A C/D만 `experienceOnly`다.

| 평형 | 타입 | 원본 변환 | 거실 방향 |
|---|---|---|---|
| 55B | C | -180°, 반전 없음 | 남동 |
| 55B | D | -90°, mirrorY | 남서 |
| 59A | C | -90°, 반전 없음 | 남동 |
| 59A | D | -90°, mirrorX | 남동 |

기존 실제 51A·55A C/D를 가상 타입으로 다시 정의하지 않았다. 모든 수동 C/D 전환에는 놀이터 중앙에 5초간 “선택한 세대의 실제 배치와 다를 수 있는 체험용 평면입니다.”를 표시한다. 입력 포커스나 이동을 막지 않고, 일반 토스트와 분리했다. 새 체험용 평면의 공유 화면에도 체험용 안내를 제공한다.

## 디자인월

- 기존 판재 recipe의 본체와 일부 줄눈 뒤쪽 면이 공면이어서 깜빡임을 유발할 수 있었다. 추가 20mm 박스와 입체 줄눈을 그리지 않고 구조벽의 공용면 하나에만 마감 재질을 지정했다.
- 범위·면 방향은 `BUNDANG_OPTION_LAYOUTS`에서 파생한다. 벽의 위치·두께·높이·개구부·충돌·레이저 장애물은 변경하지 않는다.
- 기존 prop ID와 sourceOptionId는 색·깊이를 쓰지 않는 무두께 선택 면으로 유지한다. 이 프록시는 가림 마스크나 레이저에 중복 등록하지 않는다.
- 기본 TV벽은 유지하고, 유상 해제는 기본 벽으로, 마이너스 옵션은 기본 TV벽까지 기존 규칙대로 복원한다.
- `design-wall-a042-lilt-gray`는 밝은 웜그레이지의 고운 석질 무광 표현이다. 금속성 0, 거칠기 0.9, 결정적 절차형 텍스처와 미터 좌표 UV를 사용한다. 텍스처 반복 주기는 샘플링 단위이며 실제 제품 패널 치수를 뜻하지 않는다.
- 텍스처만 공유하고 투명도 상태를 바꾸는 재질은 벽별로 소유한다. 주방 상판·인피니티 도어의 골든쇼어 재질과 기존 미리보기는 변경하지 않았다.

색·재질 근거는 각 공식 마감재리스트의 동화기업 A042 LILT GRAY다. 모델 표현은 색 보정된 실사나 시공 확정값이 아니다.

## 최소 검증

- 인증·권한 17개, 평면·세대 29개, 벽마감·배치·가림·실측 72개, 회귀·가이드 권한 6개 관련 단위 테스트가 통과했다. 전체 로컬 테스트는 실행하지 않았다.
- production build·배포 자산 검사 및 Chromium 스모크 1건이 통과했다. 스모크는 공개 위저드/오류·권한, 회원 A–D·중앙 안내, 운영자·읽기 전용 공유 및 1440/390px를 묶어 검사했다(JS 오류 0건, 가로 넘침 없음).
- 55A 남서향의 실제 렌더링을 짧게 확인했다. 옵션 OFF 기본 TV벽 2면 → ON 20면 복원, 보이지 않는 선택 면 20개·추가 finishOccluder 0개, 원본 geometry 보존, 5회 드래그·줌 및 벽 접촉 가림을 확인했다.
- 최종 색감은 기존 조명 아래 견본의 웜그레이지가 보이도록 조정했고, 주기적인 큰 구름 무늬를 제거했다. 최종 1440/390px 캡처와 이전 색감은 로컬 `tmp/public-access-wall-finish-review/`에 보관하며 공개 자산으로 복사하지 않았다.
