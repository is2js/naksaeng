# 전 평형 서비스 문 실내 열림

## 원인과 범위

다용도실·실외기실 개구부의 로컬 `interiorNormal`은 각 실 내부를 올바르게 가리키고 있었다. 그러나 기본 문 렌더러는 이 방향을 사용하지 않고 단일 문에 항상 월드 기준 양의 회전각을 적용했다. 반전은 회전의 부호도 뒤집어야 하므로, 51A·55A·59A의 B/D와 55B의 A/C에서 바깥쪽으로 열렸다.

이번 변경은 Bunfirvil의 51A·55A·55B·59A에 있는 `utility-kitchen-(east|west)-opening`과 `outdoor-unit-(east|west)-opening`의 **문짝 시각 자세만** 수정한다. 원본 PVP·생성 snapshot·정밀 벽 기하·개구부는 변경하지 않는다.

## 열림 계약

- 문 안쪽 법선을 개구부와 동일한 세대 변환으로 한 번만 월드에 옮긴다. 원점의 평행이동을 빼고 정규화해 방향만 사용한다.
- 힌지→손잡이의 닫힌 벡터와 내부 법선의 외적 부호로 열림 각도 부호를 결정한다. 따라서 회전·반전, a/b 힌지에 관계없이 해당 실 안쪽으로 열린다.
- 기존 약 30% 열림은 90°×0.30=27°로 유지한다. 문폭·높이·열림 상태·문틀·통행 폭·벽 실측은 그대로다.
- 후속 사용자 확인에 따라 서비스 문짝의 시각 힌지는 **거실 쪽 벽의 끝점**으로 맞춘다. 거실 중심을 로컬 개구부 접선에 투영해 가까운 끝을 선택하므로 카메라·A–D 방향과 무관하다. 결과는 두 문 모두 `51A b 유지 / 55A b / 55B a / 59A b`다.
- 시각 힌지가 바뀌면 새 힌지→손잡이 벡터로 실내 열림 각도 부호를 다시 계산한다. 원본 `hingeEndpoint`는 판독 근거로 보존하고, 거실/법선 근거가 없거나 투영이 동률이면 이 원본 값을 사용한다.
- 일부 옛 실외기실 데이터의 `swingDirection:"outward"`는 현재 실 내부를 가리키는 정상 `interiorNormal`과 다르므로 시각 방향 판정에 사용하지 않는다.
- 다른 침실·욕실·현관·팬트리 문의 승인된 자세, 닫힘/숨김 상태와 인피니티 도어 대체는 바꾸지 않는다.
- 유효한 서비스 문 내부 법선이 없거나 대상 평형이 아니면 기존 렌더 자세로 안전하게 돌아간다. 저장 키·옵션·가구 좌표와 외부 API는 변경하지 않는다.

## 최소 확인

실제 정밀 보정 맵의 4평형×A–D×서비스 문 2개를 `addDoor()`로 생성해 목적지 방과 같은 반평면, 27° 각도, 문폭·거실 쪽 힌지와 source 불변을 확인한다. 힌지 기대는 helper를 정답으로 복제하지 않고 거실→개구부 접선 투영과 평형별 b/b/a/b 표로 독립 대조한다. 기존 기본 문 자세·55B 연결벽·치수·통행 검사, production build·정적 출력 검사와 PC/390px의 실제 화면만 확인한다.
