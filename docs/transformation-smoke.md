# 변신 연기 자산

놀이터 핫바 `4`의 피그미 변신·변신 해제에 보랏빛 연기를 표시한다. 1개의 투명 PNG 시트에 128×128 프레임 24개가 가로로 들어 있으며, 80ms씩 1회 재생한다. 발 기준점은 시트 프레임의 (64, 109)이고 외형 표시는 시작 약 600ms에 바뀐다. 조작 상태는 지연하지 않는다.

`public/assets/effects/transformation/transform-violet-r1.png`는 승인된 보랏빛 변신 시안의 원본 효과 시트를 복사한 것이다. SHA-256은 `d9bd7612ddf1aaee8bd5db4726947b68c4ee9e712f44c7779b09b5552dc2c76b`이다. 시트에는 인물이나 배경이 들어있지 않다.

다른 버전으로 바꿀 때는 폭·프레임 수·투명도·발 기준점을 확인하고 파일 경로와 CSS 재생 설정을 함께 갱신한다. 이미지 로딩 실패 또는 운영체제의 동작 줄이기 설정에서는 효과 없이 기존 변신이 즉시 적용된다. 페이지 하위 경로에서는 `resolveProjectUrl`로 자산을 찾는다.
