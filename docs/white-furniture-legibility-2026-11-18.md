# 흰 가구·가전 형태 구분

## 범위

51A·55A·55B·59A의 고정 옵션과 기본 욕실 설비를 공통 renderer에서 점검한다. 평면별 위치·방향·치수, 충돌·실측과 사용자 배치 가구의 저장값은 변경하지 않는다. 생성 snapshot과 PVP 원본도 수정하지 않는다.

## 수정

- 침실2·3 데스크형 붙박이장: 상판은 밝은 백색, 등판은 절제된 회녹색, 측판·지붕은 중성 백색으로 분리한다. 상부장 4칸과 얕은 선반의 기존 구조를 유지하고 선반 앞선도 구분한다.
- 파우더장: 밝은 화장대 상판, 앞선과 2단 서랍 사이 이음선을 구분한다.
- 세면대: GLB의 본체와 도자기 상판·볼의 재질 그룹을 유지한다. 기존의 단색 덮어쓰기를 제거하고 하부장과 볼의 색상·거칠기를 다르게 적용한다. 원본 GLB 재질은 변경하지 않는다.
- 사용자 배치용 컴퓨터 책상 1200·800: 흰색을 선택한 경우 상판과 4개 다리의 재질을 구분한다. 목재 등 다른 색상 팔레트와 원본 recipe는 유지한다.
- LG 냉장고의 문 구획, 삼성 냉장고의 3개 문·손잡이, 양변기 부속, 붙박이장 세로 이음선, 아일랜드 빈 슬롯과 하단 서랍, 팬트리 선반과 지지대는 기존 분리 표현을 확인한다.

전역 노출·조명이나 벽·마루 색상을 올려 형태를 강조하지 않는다. 깊이 검사 해제, 가구 전체 윤곽선 오버레이나 레이저 형상의 확대도 사용하지 않는다. 고정 시점에서 가구 뒷면이나 높은 장이 실제로 가리는 면을 임의로 뚫지는 않는다.

## 검증

관련 renderer·옵션 계약 검사, 네 평형의 데스크·냉장고 실제 화면과 모바일 표본, production build 및 정적 배포 검사를 사용한다. 캡처는 로컬 `tmp/white-legibility-before/`, `tmp/white-legibility-after/`에 보관하며 공개 자산으로 복사하지 않는다.

- 관련 단위 검사 59개 통과. 4평형×A–D의 실제 옵션 프롭에서 위치·치수·원본 GLB 재질 불변과 공통 재질 적용을 검사했다.
- 1440px에서 4평형의 실제 장면, 390px에서 55B를 캡처했다. 브라우저 pageerror는 0건이다.
- 책상 정면 확인용 별도 테스트 카메라에서 상판·상부장·선반·하부 서랍을 확인했다. 이 카메라 변경은 검사용일 뿐 제품에 적용하지 않는다.
- 55A·59A A형처럼 고정 카메라가 가구 뒷면을 보는 경우나 높은 장이 상판을 가리는 경우는 정상적인 물리적 가림으로 남는다. 이번 변경은 카메라나 가구 방향을 바꿔 앞면을 억지로 노출하는 작업이 아니다.
