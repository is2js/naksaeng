# 옵션 팔레트 사용법

> 이 페이지의 옵션과 가구 배치는 현재 브라우저에만 저장되는 프론트엔드 검수용 데이터입니다.

## 옵션 선택과 견적

1. 우측 **옵션** 탭에서 원하는 카테고리를 선택합니다.
2. 옵션 카드를 누르면 세대 내부 프롭과 하단 선택 목록이 즉시 갱신됩니다.
3. 화면 좌하단에서 선택 옵션과 합산 금액을 한 줄로 확인합니다.
4. **적용만 보기**를 누르면 현재 선택된 옵션만 모아볼 수 있습니다.

옵션의 의존 조건과 배타 조건은 브라우저에서 바로 계산됩니다. 함께 사용할 수 없는 옵션은 선택 과정에서 정리되며 실제 계약이나 서버 판정에는 반영되지 않습니다.

## 마이너스 옵션

마이너스 옵션은 기본 제공 구성 중 아래 항목을 **검수 렌더에서 제외 요청**으로 표시하는 안내용 선택입니다.

- 욕실 기본 위생기구
- 실내 문짝(문 개구부와 벽체는 유지)
- 주방 기본 상판·하부장·백스플래시
- 기본 주방 렌지후드와 나비엔 매직 3구 가스쿡탑

구조 벽체·문 개구부·바닥·천장·창호와 욕실/주방의 설비벽 등은 유지합니다. 위에 적은 주방 기본 상판·하부장·백스플래시와 기본 기기, 기본 제공 TV벽 디자인 월 마감은 제외 대상이며, 마이너스 옵션은 원본 세대 구조를 삭제하거나 평면을 바꾸는 기능이 아닙니다.

마이너스 옵션은 **시스템에어컨을 포함한 모든 유상 옵션**과 동시에 선택할 수 없습니다. 이미 선택한 옵션이 있으면 모두 해제한다는 확인 후 적용하며, 적용 중에는 마이너스 옵션을 먼저 해제해야 다른 옵션을 다시 선택할 수 있습니다. 과거 저장값에 마이너스 옵션과 유상 옵션이 함께 남아 있어도 불러올 때 마이너스 옵션만 유지합니다.

| 평형 | 공급가 감액 | 발코니 확장 감액 |
| --- | ---: | ---: |
| 51A | 26,440,000원 | 780,000원 |
| 55A | 28,490,000원 | 770,000원 |
| 55B | 28,480,000원 | 680,000원 |
| 59A | 30,550,000원 | 990,000원 |

위 감액은 놀이터의 **옵션 합계에는 포함하지 않습니다**. 분양가 계산기의 자금 계획에서는 공급가와 발코니 확장비에서 각각 차감한 뒤 계약금·중도금·잔금에 안분합니다. 입주 시 대출 상환·세금·부대비용과 모기지·수익공유는 [입주·자금 계산 가이드](?guide=sale-finance)에서 확인하세요. 계산기는 실제 계약 금액을 확정하지 않습니다.

## 디자인 월과 인피니티 도어

- 거실에서 **침실1과 맞닿은 TV 쪽 벽의 디자인 월은 기본 제공**입니다. 마이너스 옵션이 아니면 유상 디자인 월을 선택하지 않아도 표시됩니다.
- **디자인 월(거실/복도면)** 유상 옵션은 기본 제공 TV벽과 냉장고면을 제외한 거실·복도 벽면에 추가 적용됩니다. 선택을 해제해도 기본 TV벽 마감은 유지되며, 마이너스 옵션을 선택하면 이 기본 마감도 표시하지 않습니다.
- 디자인 월은 A042 LILT GRAY 견본을 참고한 밝은 웜그레이지 석질 마감입니다. 벽 위에 두꺼운 판을 더하지 않고 해당 벽 표면의 재질만 교체하므로 레이저 실측 치수는 변하지 않습니다. 색감·시공 범위는 가상 표현이며 실제 마감과 다를 수 있습니다.
- 마감은 기존 구조벽을 얇게 감싸며 창문과 문 개구부를 막지 않습니다. 레이저 실측과 캐릭터·가구 충돌에서는 마감 두께를 제외합니다.
- **침실1 인피니티 도어**는 거실 또는 복도와 침실1이 만나는 실제 출입구만 손잡이 없는 디자인 월 마감 문으로 교체합니다.
- **전체 침실 인피니티 도어**는 침실1·침실2와 세대에 존재하는 침실3 또는 알파룸까지 교체하고 욕실문은 제외합니다.
- 전체 시공에 필요한 디자인 월이 선택되지 않았다면 먼저 확인창이 열립니다. **함께 선택**을 눌러야 두 옵션이 적용되며 취소하면 기존 선택을 유지합니다.

인피니티 도어는 닫힌 문처럼 보이는 검수용 마감이지만 캐릭터 이동은 통과할 수 있습니다.

## 시스템 에어컨

| 구분 | 조작 | 표시 방식 |
| --- | --- | --- |
| 일반형 | 카드의 `−`·`+` 버튼 | 제공 가능한 다음 설치 대수로 이동 |
| 고급형 | 카드의 `−`·`+` 버튼 | 등급을 유지한 채 설치 대수 조절 |
| 해제 | 선택된 카드 다시 누르기 | 옵션과 견적에서 제거 |

세대형마다 제공 대수가 다를 수 있습니다. 예를 들어 3대 구성이 없는 세대는 2대 다음에 4대로 이동합니다.

## 배치된 제품 선택

- 옵션 화면이나 **가구 배치** 탭에서 기존 가구·가전을 좌클릭하면 제품 이름과 금색 선택 마스크가 표시됩니다.
- 선택된 제품을 우클릭하면 브라우저 메뉴 대신 이동·회전·자석·삭제 메뉴가 열립니다.
- `Shift + 휠`로 90도씩 회전하고 `Delete`로 제거합니다.
- `L`을 누르면 현재 회전을 유지한 채 1.15m 안의 가까운 벽에 자석처럼 붙습니다.
- **이동**을 누른 뒤 세대 바닥을 선택하면 새 위치에 재배치됩니다.

## 가구 추가와 로컬 저장

1. **가구 배치** 탭에서 가구·가전 카드를 선택합니다.
2. PBR 세대 바닥의 원하는 위치를 클릭합니다.
3. 배치 후 드래그 이동, 회전, 벽 자석, 삭제를 사용할 수 있습니다.

배치 좌표는 0.05m 단위로 정리되며 브라우저의 로컬 저장소에 보관됩니다. 다른 기기나 브라우저와 자동으로 공유되지 않습니다.

저장 범위와 초기화 방법은 [로컬 저장·초기화 가이드](?guide=local-storage)에서 확인할 수 있습니다.

## 검수자료 관리

검수맵 관리 페이지에서는 맵별 상태·메모·옵션과 로컬 가구 배치를 JSON으로 내보내거나 가져올 수 있습니다. 원본 PVP 프로젝트에 자동 게시하는 기능은 제공하지 않습니다.
