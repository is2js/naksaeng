# 도면 치수와 모델 실측

> 이 놀이터는 평면도를 바탕으로 만든 추론 가상공간입니다. 아래 값은 공식 시공 치수나 실제 세대의 실측 확정값이 아닙니다. 가구 주문·시공 전에는 전시관·현장 실측을 확인하세요.

## 같은 곳을 재도 도면과 다른 이유

사용자가 제공한 파란 치수선 46개를 기준으로 모델을 대조했습니다. 51A·55A·59A는 외곽과 외벽을 유지하고 내부 벽의 중심·끝·최종 면 및 두께 변경을 최대 50mm로 제한했습니다. 이 세 평형의 기존 보정값은 변경하지 않았습니다.

55B는 별도 승인된 v2 정본에서 방 연결·외곽 꺾임 형태를 유지하면서 과대한 외곽·현관문·내부 구획을 도면 비례로 재작성했습니다. 과거 알파룸 약 765mm·침실2 약 700mm 깊이 차이를 보정해 12개 명시 치수는 현재 모델 면/기준선에서 일치합니다. 현관 1.50m와 팬트리 약 1.00m는 도면 비례의 추론값입니다. 이 정본에는 기존 50mm 보정표를 중복 적용하지 않습니다.

55B 알파룸 폭은 이미지에 18로 보여 **1.8m로 잠정 해석**했습니다. 공식 시공 치수로 확정된 값이 아닙니다. 사용자가 공개 열람·다운로드를 승인한 원본 참고도 4장은 미니맵 도면 모달에서 제공하며 출처·해시를 기록했습니다.

기존 저장·공유 가구의 좌표는 자동 이동·삭제하지 않습니다. 새 55B 벽과 겹치거나 바닥 밖인 경우 재배치 안내를 확인하세요. 다른 세 평형의 남은 오차도 아래 표에서 확인할 수 있습니다. 레이저 숫자를 도면값으로 치환하거나 가짜 벽을 넣지는 않았습니다.

## 실제 면과 기준선

- **실제 면**: 현재 모델에 있는 벽의 안쪽 면 사이입니다. 현장 건축물을 직접 측정했다는 뜻은 아닙니다.
- **기준선**: 벽 끝·문 끝·상판 끝의 좌표를 열린 공간으로 연장한 참고 구간입니다. 그 선에 실제 벽은 없습니다.
- 51A·55A·59A의 거실 위쪽 점선, 55B 거실 가로선의 일부 끝과 주방 일부 깊이는 기준선입니다. 자동 레이저가 그 선을 지나 더 먼 벽까지 이어지는 것은 정상입니다.
- 레이저는 바닥에서 **13cm 높이**의 현재 벽·설비·가구 면을 잽니다. 가구나 주방장·선택 옵션이 경로에 있으면 아래 구조 치수보다 짧아질 수 있습니다. 창·문 구멍과 측정 위치에 따라서도 접점이 달라집니다.
- 개방된 구간의 원하는 두 점 사이를 보려면 2점 실측을 사용하고, 실제 반대 면까지 재려면 직선 자석의 의미를 구분해 사용하세요. [조작 가이드](?guide=playground)에서 사용법을 볼 수 있습니다.

## 평형별 전후 수치

단위는 mm이며 1mm로 반올림했습니다. 잔여는 모델 후 − 도면 목표입니다. 0은 표시 정밀도에서 차이가 없다는 뜻일 뿐 실제 세대와의 일치를 보장하지 않습니다. 아래 표는 기본 가구를 뺀 구조면 기준이며, 주방 부분 구간에 적힌 상판 경계만 참고합니다. 같은 평형의 A/B/C/D는 회전·반전하므로 이 국소 길이는 같습니다.

## 이 수치의 사용 범위

모델을 비교하고 배치 아이디어를 살펴보는 참고값으로 사용해 주세요. 실제 시공 종료선·벽 두께·창호·가구 규격과 다를 수 있습니다. 정확한 설치 가능 여부와 비용은 공식 공고문·전시관·현장 실측으로 확인해야 합니다.
