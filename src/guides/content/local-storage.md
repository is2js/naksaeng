# 로컬 저장·초기화

:::shared
## 공유 화면은 저장하지 않습니다

- 공유 링크의 옵션과 가구는 현재 화면의 **메모리에서만** 열람합니다. 자신의 브라우저에 저장된 옵션·가구 배치를 덮어쓰지 않습니다.
- 공유 화면에서는 저장 관리·초기화와 옵션·가구 변경을 사용할 수 없습니다. 운영자로 열어도 동일합니다.
- 공유 화면을 나가면 링크의 내용을 자신의 배치로 저장하지 않으며, 기존 일반 놀이터의 저장 정보는 그대로 남습니다.
:::

:::public member
> 옵션 구성은 계정 서버가 아닌 현재 브라우저의 로컬 저장소에 남습니다. 다른 기기와 자동으로 동기화되지 않습니다.

## 무엇이 저장되나요?

| 구분 | 저장 범위 | 로컬 저장 키 |
| --- | --- | --- |
| 선택 옵션 | 평형별, 모든 평면 타입 공통 | `bunfirvil:review:v1:<mapId>` |
:::

:::member
사용자 가구 배치는 아래 키에 별도로 저장됩니다.

| 구분 | 저장 범위 | 로컬 저장 키 |
| --- | --- | --- |
| 추가·이동·회전·삭제한 가구 | 평형별, 모든 평면 타입 공통 | `bunfirvil:layout:v1:<mapId>` |
:::

:::operator
검수·관리 기록과 기존 핫바 저장 계약은 다음과 같습니다. 옵션과 검수 상태·메모는 같은 평형 키를 사용합니다.

| 구분 | 저장 범위 | 로컬 저장 키 |
| --- | --- | --- |
| 옵션·검수 상태·메모 | 평형별, 모든 평면 타입 공통 | `bunfirvil:review:v1:<mapId>` |
| 건축물 관리자 검수 | 평형과 평면 타입별 | `bunfirvil:building-admin:v1:<mapId>:<A–D>` |
| 스킬 핫바 | 모든 평형 공통 | `bunfirvil:hotbar:v1` |
:::

:::public member
선택한 동·층·호는 놀이터의 평면과 방향, 분양가 층 가격구간을 정하는 데 사용합니다. 동·호·실제 층은 위 로컬 옵션 저장 키에 기록하지 않습니다.

분양가 계산기의 금리·청약 구분·예정일·세금·대출·부대비용 가정은 `bunfirvil:sale-calculator-preferences:v1`에 현재 탭 한정(`sessionStorage`)으로 보관합니다. 타입·층 가격구간만 함께 기록하며 동·호·실제 층·닉네임·인증정보를 넣지 않습니다. 세대 재선택, 타입·층 가격구간 변경, 전체 초기화 또는 탭 종료 시 제거됩니다. 옵션·가구의 `localStorage` 저장 키는 경로 이전 전후에도 그대로 사용합니다.

같은 평형의 옵션과 기존에 저장된 가구 배치는 동·층·호가 달라도 함께 사용합니다. 예를 들어 55A A형에서 저장한 옵션은 55A B·C·D형과 다른 동의 55A 세대에도 동일하게 표시됩니다.

## 현재 평형만 초기화

메인 쇼케이스의 옵션 패널 상단에서 **저장 관리**를 열고 **현재 평형 옵션·가구 초기화**를 누릅니다.

- 현재 평형의 선택 옵션을 비웁니다.
- **이전에 저장된 가구 배치도 함께 초기화**됩니다. 지금 가구 편집을 사용하지 않더라도 기존 기록이 있다면 영향을 받습니다.
- 검수 상태·메모, 건축물 관리자 기록과 핫바는 유지합니다.
- 같은 평형의 모든 평면 타입과 모든 세대에 공통으로 적용됩니다.

## 전체 초기화

세대 선택 화면 또는 메인 쇼케이스의 **저장 관리**에서 **Bunfirvil 전체 로컬 데이터 초기화**를 누릅니다. Bunfirvil의 옵션·가구·검수·건축 기록과 핫바만 삭제하며 같은 GitHub Pages 주소를 사용하는 다른 프로젝트의 저장 정보는 건드리지 않습니다.

전체 초기화는 되돌릴 수 없습니다. 옵션뿐 아니라 이전에 저장된 가구와 관리 기록에도 영향을 주므로 삭제 범위를 확인한 뒤 진행하세요.
:::

:::operator
## 운영자 백업

초기화 전 필요한 검수정보는 **검수맵 관리** 페이지에서 JSON으로, 가구 배치는 **인테리어 관리** 페이지에서 평형별 JSON으로 먼저 내보내세요.
:::

:::public member
## 브라우저와 기기를 바꾸는 경우

- 다른 브라우저, 시크릿 창, 다른 기기와 자동으로 공유되지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 함께 사라질 수 있습니다.
- 이 사이트를 새로 배포해도 브라우저의 로컬 저장정보는 자동으로 삭제되지 않습니다.
:::
