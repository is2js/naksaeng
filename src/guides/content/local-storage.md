# 로컬 저장·초기화

> Bunfirvil은 서버와 계정 저장소를 사용하지 않습니다. 모든 편집 정보는 현재 브라우저의 로컬 저장소에만 남습니다.

## 무엇이 저장되나요?

| 구분 | 저장 범위 | 로컬 저장 키 |
| --- | --- | --- |
| 옵션·검수 상태·메모 | 평형별, 모든 평면 타입 공통 | `bunfirvil:review:v1:<mapId>` |
| 추가·이동·회전·삭제한 가구 | 평형별, 모든 평면 타입 공통 | `bunfirvil:layout:v1:<mapId>` |
| 건축물 관리자 검수 | 평형과 평면 타입별 | `bunfirvil:building-admin:v1:<mapId>:<A–D>` |
| 스킬 핫바 | 모든 평형 공통 | `bunfirvil:hotbar:v1` |

동·층·호 선택 정보는 평형과 A–D 쇼케이스를 정하는 동안에만 사용하며 저장하거나 서버로 전송하지 않습니다.

분양가 계산기의 금리·청약 구분·예정일·세금·대출·부대비용 가정은 `bunfirvil:sale-calculator-preferences:v1`에 현재 탭 한정(`sessionStorage`)으로 보관합니다. 타입·층 가격구간만 함께 기록하며 동·호·실제 층·닉네임·인증정보를 넣지 않습니다. 세대 재선택, 타입·층 가격구간 변경, 전체 초기화 또는 탭 종료 시 제거됩니다. 옵션·가구의 `localStorage` 저장 키는 경로 이전 전후에도 그대로 사용합니다.

같은 평형의 옵션과 가구 배치는 동·층·호가 달라도 함께 사용합니다. 예를 들어 55A A형에서 저장한 옵션은 55A B·C·D형과 다른 동의 55A 세대에도 동일하게 표시됩니다.

## 현재 평형만 초기화

메인 쇼케이스의 옵션 패널 상단에서 **저장 관리**를 열고 **현재 평형 옵션·가구 초기화**를 누릅니다.

- 현재 평형의 선택 옵션을 비웁니다.
- 현재 평형에서 추가·이동·회전·삭제한 가구 배치를 기본값으로 되돌립니다.
- 검수 상태·메모, 건축물 관리자 기록과 핫바는 유지합니다.
- 같은 평형의 모든 평면 타입과 모든 세대에 공통으로 적용됩니다.

## 전체 초기화

세대 선택 화면 또는 메인 쇼케이스의 **저장 관리**에서 **Bunfirvil 전체 로컬 데이터 초기화**를 누릅니다. Bunfirvil의 옵션·가구·검수·건축 기록과 핫바만 삭제하며 같은 GitHub Pages 주소를 사용하는 다른 프로젝트의 저장 정보는 건드리지 않습니다.

전체 초기화는 되돌릴 수 없습니다. 필요한 검수정보는 **검수맵 관리** 페이지에서 JSON으로, 가구 배치는 **인테리어 관리** 페이지에서 평형별 JSON으로 먼저 내보내세요.

## 브라우저와 기기를 바꾸는 경우

- 다른 브라우저, 시크릿 창, 다른 기기와 자동으로 공유되지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 함께 사라질 수 있습니다.
- 이 사이트를 새로 배포해도 브라우저의 로컬 저장정보는 자동으로 삭제되지 않습니다.
