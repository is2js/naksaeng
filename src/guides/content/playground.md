# 놀이터 조작

> 이 놀이터는 평면도와 사이버주택전시관을 바탕으로 구성한 추론 가상공간입니다. 게시 자료는 참고용입니다.

## 공개 입장과 회원 기능

- 동·세대를 선택한 뒤 닉네임을 입력하면 누구나 **공개 권한**으로 입장할 수 있습니다. 옵션 선택, 분양가 계산기, 이동·실측·공유를 사용할 수 있습니다.
- **인증 확인**으로 회원 인증을 마치면 가구 배치, 평면 타입 전환, 변신을 추가로 사용할 수 있습니다. 등록 대기·반려·회원 중지·인증 서비스 장애 상태에서도 공개 기능은 이용할 수 있습니다.
- 공개 핫바는 **1 텔레포트 · 2 성별 전환 · 5 자녀 인형**만 표시하며, 번호는 바뀌지 않습니다. 가구 배치 탭과 3·4번 단축키는 인증 회원 전용입니다.
- 운영자 관리 메뉴는 별도 운영자 인증을 마친 경우에만 보입니다. 공유 화면은 역할과 관계없이 읽기 전용입니다.

## 놀이터 안에서 가이드 보기

- 상단 **가이드** 또는 **?**를 누르면 놀이터를 나가지 않고 가이드 패널을 열 수 있습니다. 문서 선택으로 조작·옵션 안내를 바꾸고 **×** 또는 **Esc**로 닫으면 원래 화면에서 이어서 사용할 수 있습니다.
- **옵션 가이드**와 패널의 **새 탭에서 보기**는 별도 탭으로 열립니다. 가이드의 **놀이터로 돌아가기**는 기존 평형·평면 방향·캐릭터를 유지한 놀이터로 돌아갑니다. 옵션과 사용자 가구 저장 범위는 달라지지 않습니다.

## 모바일 터치 조작

- 놀이터는 페이지 최상단에서 시작하며, 맵 안에서는 캐릭터를 중심으로 화면이 표시됩니다. 왼쪽 아래 **원형 조이스틱**을 원하는 방향으로 누르거나 밀면 8방향으로 이동하고 화면도 부드럽게 따라옵니다. 손가락을 떼거나 가운데로 옮기면 멈춥니다.
- 모바일은 **65% 배율**로 시작하며, 우상단에 **지도와 현재 위치·북쪽 방향**, 확대·축소 버튼을 표시합니다. 맵 설명 제목과 미니맵 범례는 숨깁니다. 표시된 핫바는 탭으로 사용할 수 있으며, 텔레포트는 세대 안의 이동 가능한 위치로 이동합니다. 큰 공격·취소 버튼은 표시하지 않습니다.
- 맵의 빈 공간을 **한 손가락으로 위아래 드래그**하면 일반 페이지처럼 스크롤합니다. **두 손가락을 함께 드래그**하면 자동 추적을 잠시 멈추고 지도를 이동해 둘러볼 수 있습니다. 다시 조이스틱으로 이동하면 캐릭터 중심 추적이 재개됩니다.
- 우상단 **＋/−**로 확대·축소하고 가운데 비율 버튼으로 기본 65% 배율로 돌아갑니다.
- 모바일에서는 별도 선택 옵션 상자 대신 **옵션 팔레트 하단의 고정 합계와 큰 분양가 계산기 버튼**을 사용합니다. 옵션 목록을 스크롤해도 합계와 계산기 버튼은 팔레트 아래에 유지되며, 옵션 카드를 다시 눌러 선택을 해제할 수 있습니다.
- 가구 카드를 선택하고 맵을 **터치·드래그**해 위치를 정합니다. 초록색이면 **배치 확정**을 누르세요. 배치 중 **↶/↷·자석·취소**를 사용할 수 있습니다.
- 배치한 사용자 가구는 탭한 뒤 **이동·회전·자석·삭제** 버튼으로 편집합니다. 가구배치·실측·설정 중에는 이동판과 자동 추적이 간섭하지 않으며, 가구배치에서 옵션 탭으로 돌아오면 캐릭터 중심 화면을 복원합니다.
- **레이저 실측** 버튼으로 켠 뒤 측정할 곳을 탭합니다. **2점 실측** 버튼을 누르면 첫 점과 끝점을 차례로 탭해 잴 수 있고 **직선 자석** 버튼으로 벽·가구 면에 맞춥니다.
- 우하단의 작은 **실측** 버튼을 누르면 레이저가 켜지고, 같은 버튼의 **실측 종료**를 누르면 꺼집니다. 가구 배치는 배치 도구의 **취소**로 종료합니다. 설정창이 열리거나 화면을 벗어나면 조이스틱 입력은 멈춥니다.

## 데스크톱 이동과 화면

- **WASD 또는 방향키**: 바라보는 방향을 유지하며 한 셀씩 이동합니다.
- 대각선 이동 후 두 키를 차례로 떼어도 마지막 대각선 방향을 유지합니다. 한 키를 계속 누르면 해당 방향으로 전환합니다.
- 문과 좁은 통로는 실제 벽·설비 경계를 기준으로 이동합니다. 문 가장자리와 사선 진입도 가능하지만 벽 본체와 설비 안으로 통과할 수는 없습니다.
- **Space**는 기본 공격을 실행합니다.
- **빈 화면 드래그**: 손바닥 커서로 평면도를 이동합니다.
- **Ctrl + 휠**: 캐릭터와 평면도를 함께 확대·축소합니다.

## 핫바 1–5

1 텔레포트 · 2 성별 전환 · 3 평면 타입 전환(인증 회원) · 4 변신(인증 회원) · 5 자녀 인형

1. **텔레포트**: 마우스 위치로 이동하며 화면 중심도 캐릭터를 따라갑니다. 마우스 휠 버튼으로도 실행할 수 있고, 재사용 대기시간은 2초입니다. 세대 바깥을 가리키면 세대 내부의 이동 가능한 위치로만 이동합니다.
2. **성별 전환**: 남성·여성 캐릭터 외형을 전환합니다. 캐릭터 이름은 입력한 닉네임으로 유지되며, 공유 놀이터에서는 공유자의 닉네임이 표시됩니다. 변신 중이면 변신이 먼저 해제됩니다.
3. **평면 타입 전환**: 인증 회원은 각 평형의 A→B→C→D를 순환합니다. 선택 옵션과 가구 배치는 유지됩니다. C/D로 직접 전환하면 화면 중앙에 선택한 세대의 실제 배치와 다를 수 있다는 안내가 나타납니다. 기존 51A·55A의 실제 호라인 C/D는 그대로이며, 새 55B·59A C/D는 체험용입니다.
4. **변신**: 피그미·두건덩치·머미킹·아이언골렘·표범 중 준비된 모습 하나로 무작위 변신하거나 해제합니다. 변신할 때 연기가 나타나고, 활성 중에는 슬롯 외곽선이 움직입니다. 이미지를 불러오는 중이거나 오류가 난 모습은 준비된 후 선택됩니다.
5. **자녀 인형**: 자녀수(1–6명)를 고른 뒤 각 자녀의 연령대와 성별을 차례로 선택해 인형을 소환합니다. 다시 열어 변경하거나 소환을 해제할 수 있습니다. 인형은 캐릭터 뒤에서 조금 늦게 따라오며, 여러 명은 2셀 범위에서 서로 다른 간격과 속도로 따라옵니다. 인형은 자신이 움직이는 방향을 바라보고 멈추면 대기합니다. 이 설정은 저장·공유되지 않습니다.

## 레이저 실측

- 데스크톱은 좌하단 **레이저 실측**, 모바일은 우하단 **실측** 버튼으로 켜고 끕니다.
- **J**를 누를 때마다 자동 실측과 2점 실측을 전환합니다.
- 2점 실측은 벽·설비·가구 면에 첫 점을 고정한 뒤, **L OFF**에서 원하는 자유 종점을 찍습니다.
- **Shift**를 누르면 세대 로컬 X/Y 네 방향 중 마우스에 가까운 직선으로 제한되며, 반대 면까지 연장하지 않고 마우스 투영점에서 끝납니다.
- **L ON**은 반대쪽 벽·가구 면에 자석 고정하며, 이때 **Shift + 휠**로 축을 전환합니다. **Esc**는 레이저 실측을 종료합니다.
- 레이저는 바닥에서 13cm 높이의 모델 벽·설비·가구 표면을 기준으로 측정합니다. 도면 표기와 모델의 크기가 다를 수 있으므로 실제 시공 치수나 계약상 치수의 확정값으로 사용하지 마세요.

## 가구 배치

- 인증 회원과 운영자만 가구를 편집할 수 있습니다. 공개 사용자는 저장된 가구를 볼 수 있지만 가구 배치 탭과 편집 도구는 표시되지 않습니다.
- **가구배치** 탭의 카드를 선택하면 고스트가 마우스를 따라오며 초록색은 설치 가능, 빨간색은 설치 불가 영역입니다.
- 사용자가 추가한 가구는 드래그로 재배치하고 **Shift + 휠**로 회전하며 **L**로 가까운 벽에 붙일 수 있습니다.
- 선택한 사용자 가구는 **Del**로 삭제할 수 있습니다.
- 기본 제공 인테리어와 옵션 구성은 정확한 기본 위치를 보존하기 위해 이동·회전·삭제할 수 없습니다.
- **현관 중문**은 통로 폭에 맞춰 설치되는 고정 옵션입니다. 가구 목록의 현관 중문을 누르면 해당 옵션 카드로 안내되며, **옵션** 탭에서 직접 선택해야 적용됩니다.

## 취소와 저장

- **Esc**: 진행 중인 가구 고스트나 레이저 측정을 취소합니다.
- 옵션과 사용자 가구 배치는 서버가 아닌 현재 브라우저에만 저장됩니다.

## 읽기 전용 공유

- 상단 **공유** 버튼은 현재 평면 방향, 선택 옵션과 사용자가 배치한 가구만 압축한 링크를 복사합니다.
- 공유 링크에는 공유자 닉네임이 표시용으로 포함됩니다. 동·층·호·인증 역할·검수 메모·관리자 기록·캐릭터 정보는 들어가지 않습니다.
- 링크를 받은 사람은 동을 선택하고 닉네임을 입력하면 공개 권한으로 열람할 수 있으며, 별도 세대 선택이나 회원 승인은 필요하지 않습니다.
- 공유 열람에서는 캐릭터 이동, 텔레포트, 화면 이동·확대, 레이저 실측만 사용할 수 있습니다. 옵션·가구·평면은 변경하거나 저장할 수 없습니다.
- 공유 평면과 방향은 링크 안의 데이터로 결정합니다. 주소의 평형 쿼리가 빠져 있어도 동일한 공유 놀이터를 열며, 손상된 링크는 인증 전에 차단합니다.
- 배치 가구는 최대 200개까지 공유할 수 있습니다. 개수나 링크 크기 제한을 넘으면 링크를 만들지 않으며 가구를 임의로 생략하지 않습니다.
